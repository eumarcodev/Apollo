## ℹ️ About

Helios is a self-hosted game stream host for Moonlight.

The documentation lives in the [docs](https://github.com/eumarcodev/Helios-Server/tree/develop/docs) folder of the Helios repository.

This repo is synced from the upstream [Helios](https://github.com/eumarcodev/Helios-Server) repo.
Please report issues and contribute to the upstream repo.
